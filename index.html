FFXIV Visual Codex

About

Greetings and welcome to the XIV Visual Codex. The purpose behind this project is to create a wiki for Final Fantasy XIV using the UI from The Thousand Tomes system featured in Final Fantasy XVI as I felt that the codex that Square Enix used in that game was one of the best ive ever seen in a video game. As a big fan of Final Fantasy XIV, I sometimes find it rather difficult to keep track of all of the game's lore due to the massive size of it's narrative. I hope with this system it can provide users with a more digestable means of keeping track of all of lore the game has to offer. I will be continously updating this wiki as time goes on so stay tuned for more updates.
